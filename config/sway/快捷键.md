# Sway (Intel)

注销后，在 greetd/ReGreet 会话菜单选择 **Sway (Intel)** 或 **Sway**。
Win 表示键盘 Windows / Super 键。

| 快捷键 | 功能 |
|---|---|
| Win + Enter | 终端 |
| Win + Space / D | 应用启动器 |
| Win + B / E | 浏览器 / 文件管理器 |
| Win + Q / Alt + F4 | 关闭当前窗口 |
| Win + 方向键 / H J K L | 切换窗口焦点 |
| Win + Shift + 方向键 | 移动窗口 |
| Win + 1…9 / 0 | 工作区 1…10 |
| Win + Shift + 数字 | 把窗口移到工作区 |
| Win + Tab | 返回上一个工作区 |
| Win + Ctrl + 左右 | 切换屏幕焦点 |
| Win + Ctrl + Shift + 左右 | 把窗口移到另一屏 |
| Win + F | 全屏 |
| Win + Shift + Space | 浮动 / 平铺 |
| Win + V / 反斜杠 | 上下 / 左右分割 |
| Win + W / S / T | 标签 / 堆叠 / 平铺布局 |
| Win + R，方向键，Esc | 调整窗口大小，退出调整 |
| Win + 鼠标左键 / 右键拖动 | 移动 / 调整窗口 |
| Win + 减号 / 等号 | 隐藏到暂存区 / 显示暂存窗口 |
| Win + Shift + S | 选区截图，保存并复制 |
| Print | 全屏截图，保存并复制 |
| Win + Esc | 锁屏 |
| Win + Shift + C | 重新加载配置 |
| Win + Shift + E | 确认后退出登录 |
| Win + Ctrl + T | 壁纸选择工具（打开时运行一次 matugen） |

登录时恢复上次壁纸并运行一次 matugen；选择新壁纸时同步更新 Sway/Waybar 配色。
Waybar 时钟：左键壁纸选择、右键随机静态壁纸、中键随机视频壁纸。
Sway 独立配色配置：`~/.config/sway/matugen/config.toml`。
壁纸/配色日志：`~/.local/state/sway/matugen.log`。

外屏 HDMI-A-1：2560×1440 @ 143.999Hz，左侧，125%。
内屏 eDP-1：1920×1080 @ 165.008Hz，右侧，125%。
Intel 核显渲染并驱动内屏。HDMI 接口连接 NVIDIA，仅用 Intel 的会话不能驱动此接口；上述外屏设置用于 NVIDIA 会话。
登录后用 `swaymsg -t get_outputs` 查看实际模式。
Intel 启动日志：`~/.local/state/sway/intel.log`。
Intel 会话配置：`~/.config/sway/config-intel`，包含主配置 `config`。
内屏缩放 1.25，使用 nearest 过滤；图像边缘可能稍显锯齿。
X11 使用 xwayland-satellite，输出仍为 1.25 倍，Xft.dpi 为 120。
独立 Chrome/X11 与 GTK/X11 测试窗口已由用户确认明显清晰。
普通 Chrome 启动项在 Sway 下使用 X11 和 1.25 UI 缩放；完全退出旧 Chrome 后再启动。
启动脚本必须明确保留 `WLR_BACKENDS=drm,libinput`，避免预设 DISPLAY 导致误选 X11 后端。
回退：用 `~/.config/sway/backups/sway-intel-20261005-before-verified-satellite` 恢复 `~/.local/bin/sway-intel`，再登录。
原配置：`~/.config/sway/backups/config-20260928-before-nvidia`。

配置校验通过；Intel 会话的实际内屏启动和刷新率需要登录确认。
